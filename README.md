## 🎮 Overview

**KUGOFOX Arena** is a next-generation esports tournament and scrims platform featuring live bracket management, in-game player IGN verification, interactive loot crates, 3D interactive esports gear, and Web Audio synthesizers.

### 🏆 Featured Games
- **Free Fire** (UID In-Game Verification)
- **Mobile Legends: Bang Bang** (Player ID Verification)
- **Valorant** (Riot ID Verification)
- **PUBG: Battlegrounds** (Character ID Verification)
- **Clash Royale** (Player Tag Verification)

---

## ⚡ Features

- **🌐 Custom Domain**: Fully active with automated SSL at [https://www.kugofox.in](https://www.kugofox.in).
- **🛡️ Player IGN Verification**: Live API-powered verification with rank detection.
- **🎧 3D RGB Esports Headset**: Interactive 3/4 perspective mouse-tracking parallax with 5 dynamic RGB lighting presets.
- **💥 Loot Crate Simulator**: Real-time mystery crate unboxing with procedural sound design.
- **🔐 Google & Custom Authentication**: Seamless authentication with persistent player profiles.
- **📊 Real-time MongoDB Backend**: Live tournament registrations, community chat, and global leaderboard rankings.

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Xani113/kogofox-arena.git
cd kogofox-arena

# Install dependencies
npm install

# Run the local development server
npm start
```

Visit `http://localhost:5173` to explore the arena locally.
